# dsh-xuexi · 网课模式

> **工具只当手和眼，判断全归大模型。**

一个 [DeepSeek Harness](https://github.com/deepseek-ai) 插件 + Agent 预设：
接管你正在用的浏览器，按真实学习的方式把网课任务做完。

---

## 这是什么，为什么这么做

大部分"网页自动化脚本"的思路是：**把页面结构写死进代码**。
页面一变就崩，于是不断加 `if`，最后没人敢改。

这个插件走的是相反的路：

```
大模型   = 大脑：看、判断、决定、应对没见过的情况
15 个工具 = 手和眼：点、写、滚、截图、取事实 —— 不认识任何网站
```

### 这是被一次真实事故逼出来的

旧版本把「某个网站长什么样」写死在工具里，又把「按什么顺序调工具」写进提示词。
用户换了一个学校的账号 —— 页面结构不一样：

- 专用工具报"课程不存在"（其实是它自己那个读法没读到）
- 想换回用户翻好的那一页，却**根本没有"换标签页"这个工具**
- 想直接点课程卡片，可通用眼睛那次没看见内嵌窗口里的东西
- 结果：**原地打转十分钟**，最后要用户手动帮它打开页面

根因不是模型笨，是**它的退路被堵死了**。

所以 v2 只做三件事：

| # | 原则 | 落地方式 |
|---|---|---|
| ① | **工具只认识屏幕** | 编号、对账清单、票据指纹 —— 全部从屏幕上现读，代码里没有业务概念 |
| ② | **格式错在动手之前拦住** | 每个工具第一步是纯计算校验；`ARG`/`USAGE` 失败 = **页面一下都没被碰过** |
| ③ | **大脑永远有退路** | 截图 → 列出能点的 → 点一个看变化。这三件永远不会失效 |

## 15 个工具

### 眼（5）—— 只报事实

| 工具 | 干什么 |
|---|---|
| `eye_open` | 接管浏览器，报现在开着哪几个标签页、我接的是哪个、登录没有、以前的笔记 |
| `eye_see` | 这一页有几处要处理、每处是**挑**还是**写**、有几个选项、有没有"已完成"标记 |
| `eye_list` | 所有能点能填的东西（**含内嵌窗口**），每个一个编号 |
| `eye_shot` | 截图 —— **图直接放在返回里，模型真的能看到** |
| `eye_check` | 交之前复核，七条全过才发**票据** |

### 手（6）—— 只做一个动作

| 工具 | 干什么 |
|---|---|
| `hand_click` | 点（编号 / 文字 / 坐标） |
| `hand_pick` | 从页面给出的选项里挑 —— 单选 / 多选 / 判断 / 下拉**对它都是同一件事** |
| `hand_write` | 在指定的可写区里写字，写完**回读**实际内容 |
| `hand_scroll` | 滚 |
| `hand_goto` | **唯一的导航**：跳网址 / 后退 / 刷新。工具绝不自作主张跳页 |
| `hand_tab` | 换浏览器标签页 |

### 必要（4）—— 只有两类动作需要代码兜住

| 工具 | 为什么必须由代码守 |
|---|---|
| `hand_play` | **铁律**：原速 1x、永不拖进度条、永不伪造心跳、严格串行。参数里故意没有倍速/跳转/心跳 |
| `hand_submit` | **做错回不了头**：不接受任何答案，只读页面 + 两份复核登记，自己再核一遍才点 |
| `hand_note` | 笔记本 + 待办清单（下次 `eye_open` 带回来） |
| `hand_verdict` | 复核员专用（唯一对子智能体开放的工具） |

---

## 做题怎么写：三方独立复核

答题是全站唯一**做错回不了头**的动作（一般不给重做），所以交之前要三方独立：

```
① 主脑自己看图定一份，用 hand_pick / hand_write 弄在**页面上**
   ★ 先弄完，再派人。别把自己那份告诉任何人。

② 派两个常驻复核员，给同一张截图 + 一份无答案编号清单

③ 它们各自 hand_verdict 登记（值写图上看得见的标签："B" / "对"）

④ eye_check 三方比对 → 通过才发票据 → hand_submit
```

**为什么主脑的答案必须落在页面上**：旧版主脑把复核员的 JSON 原样转发，
6 次提交和复核员给的 6 份一字不差 —— 实质只有一份判断，一个错就没人兜住。
现在工具直接读页面上的 `filled`，**想报一个假答案，它做不到**。

**没有 `afterReview` 后门**：不一致时**永远不发票据**。
放行只有一条路 —— 复核员拿到特写后重新登记、且新结论一致。
登记是"每人一份当前结论、整体覆盖"，身份由 `ctx.agents` 判定，不靠自报。

## 边界

**只有四种情况会当场打断你**：图形验证码 / 未登录 / 熔断或额度 / 人脸抓拍。
其余（听力题、看视频才能答的题、讨论帖）一律 `hand_note({ tag:"pending" })` 记账，做完一次性汇报。

**铁律六条**（代码会拦）：

```
原速 1x ｜ 永不拖进度条 ｜ 永不伪造心跳 ｜ 严格串行 ｜ 不破解验证 ｜ 不代填账号密码
```

**人脸识别 / 抓拍直接拒绝** —— 它要求摄像头前坐着真人，原理上做不到。

## 安装

```powershell
# 1. 装进 DSH 桌面配置档
.\install.ps1

# 2. 重启 DSH
# 3. 设置 → Agent 预设 → 选「网课模式」
```

需要一个开了调试端口的浏览器（默认 `9222`）：

```powershell
chrome.exe --remote-debugging-port=9222 --user-data-dir="$env:USERPROFILE\.dsh\xuexi\browser-profile"
```

## 测试

```powershell
npm test
```

断言分五组：参数校验（含**零副作用**的结构保证）、复核闸门（七条 + 票据 + 登记覆盖）、
工具表面（15 个、前缀、并发标志、铁律参数里不许有倍速）、痕迹检查（代码里不许有平台字样和写死的网址）、
预设自检。

## 仓库结构

```
index.js                15 个工具 + 统一外壳 + 前置校验 + 角色闸门
lib/
  args.mjs              ★ 参数校验（纯函数，零副作用）
  gate.mjs              ★ 复核七条 + 票据指纹 + 登记簿（纯函数，可测）
  browser.mjs           CDP：标签页 / 截图 / 跨窗口 / 自愈重连
  see.mjs               看：四类区域 + 编号清单
  hand.mjs              手：点 / 挑 / 写 / 滚 / 播
  note.mjs              笔记本 + 过程文件
prompts/xuexi-mode.md   模式提示词
facts/平台事实.md        经验种子（不是规则，用完让位给真实观察）
```

**过程文件落在哪**：`<工作区>/.xuexi/`（截图、笔记、记账）—— 跟对话在一起，好清理。
**机器状态**：`~/.dsh/xuexi/browser-profile`（登录态，跨会话共用）。
