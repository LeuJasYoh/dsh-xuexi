# dsh-xuexi · 网课模式

> **工具只当手和眼，判断全归大模型。**

**当前版本 2.3.0-rc.1** ｜ 许可 [MIT](LICENSE) ｜ 平台 Windows ｜ 更新日志 [CHANGELOG.md](CHANGELOG.md)

一个 [DeepSeek Harness](https://github.com/LeuJasYoh/dsh-xuexi)（简称 DSH）插件 + Agent 预设：
**接管你正在用的浏览器，按真实学习的方式把网课任务做完。**

它不认识任何网站 —— 它认识**屏幕**。课程页面长什么样、题在第几个框里、
点哪个按钮算「下一节」，这些一律不写进代码，全部由大模型当场看图判断。

## 这是什么

一句话：**17 个工具 = 手和眼，大模型 = 大脑。**

```text
大模型    = 大脑：看、判断、决定、应对没见过的情况
17 个工具 = 手和眼：点、写、滚、截图、取事实 —— 不认识任何网站
```

工具只做两件事之一：**报告它看到的事实**，或者**执行你指定的一个动作**。
「这是什么、该做什么、做不到怎么办」—— 全是模型的事，工具一概不替你判断。

配合它的是一个 Agent 预设「网课模式」：装上之后，你在 DSH 里切到这个模式、
把要做的那一页在浏览器里翻好，然后说一句「接管浏览器，把这一页做完」就行。

---

## 解决什么问题

大部分「网页自动化脚本」的思路是**把页面结构写死进代码**：课程列表在第几个
`div` 里、完成标记是什么类名、下一节按钮叫什么。页面一变就崩，于是不断加
`if`，最后没人敢改。

这个插件走的是相反的路。它诞生于一次真实事故：

```text
旧版本把「某个网站长什么样」写死在工具里，又把「按什么顺序调工具」写进提示词。
用户换了一个学校的账号 —— 页面结构不一样：
  · 专用工具报「课程不存在」（其实是它自己那个读法没读到）
  · 想换回用户翻好的那一页，却根本没有「换标签页」这个工具
  · 想直接点课程卡片，可通用眼睛那次没看见内嵌窗口里的东西
  · 结果：原地打转十分钟，最后要用户手动帮它打开页面

根因不是模型笨，是它的退路被堵死了。
```

所以 v2 只守三条原则：

| # | 原则 | 落地方式 |
|---|---|---|
| ① | **工具只认识屏幕** | 编号、对账清单、票据指纹 —— 全部从屏幕上现读，代码里没有业务概念 |
| ② | **格式错在动手之前拦住** | 每个工具第一步是纯计算校验；`ARG` / `USAGE` 失败 = **页面一下都没被碰过** |
| ③ | **大脑永远有退路** | 截图 → 列出能点的 → 点一个看变化。这三件永远不会失效 |

## 适用与不适用

**适用**：任何在浏览器里做的网课任务 —— 看视频、翻文档、做测验、进页面再出来。
不挑站点，因为站点相关的东西一概不写进代码。

**做不到、会交回给你**（它会记下来，做完一次性汇报，不中途打断你）：

| 情况 | 归宿 |
|---|---|
| 答案要靠**听**才知道 | 交给用户（模型没有听觉） |
| 答案要靠**看视频内容**才知道 | 交给用户（模型读不到画面语义） |
| **讨论帖 / 发帖** | 归用户 |
| **图形验证码** | 不破解，交给人 |
| **人脸 / 抓拍** | 直接拒绝（要求摄像头前坐着真人，原理上做不到） |

**只有四种情况会当场打断你**：图形验证码 / 未登录 / 熔断或今日额度 / 人脸抓拍。
其余一律 `hand_note({ tag:"pending" })` 记账，做完一次性汇报。

## 环境要求

| 项 | 要求 | 备注 |
|---|---|---|
| 操作系统 | **Windows 10/11** | 安装脚本是 PowerShell 脚本，硬依赖 Windows；暂不支持 macOS / Linux |
| DeepSeek Harness | ≥ 0.2.0（桌面版） | 见 `package.json` → `dsh.engines.dsh` |
| Node.js | ≥ 20 | 一般用 DSH 自带运行时，不需单独装 |
| 浏览器 | Chrome / Edge / Chromium 任一 | 插件**自己发现并启动**；也可用 `DSH_BROWSER_PATH` 指定 |
| 调试端口 | 9222（默认） | 被占用时改 `cordis.patch.yml` 里的 `config.port` |

安装脚本还需要 DSH 自带的 node 与 pnpm
（位于 `~/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/`），缺任一项会直接报错退出。

## 安装

在**插件目录**里执行（脚本靠 `$PSScriptRoot` 定位源码）：

```powershell
# 1. 装进 DSH 桌面配置档（默认配置档 desktop）
.\install.ps1

# 可选参数
.\install.ps1 -DryRun                       # 只看会改什么，什么都不动
.\install.ps1 -ProfileName default          # 装到别的配置档
.\install.ps1 -VerifyOnly                   # 只校验已安装副本，不改任何东西
.\install.ps1 -Rollback "<.bak- 备份路径>"   # 回滚到安装前的 package.json
.\install.ps1 -NonInteractive               # 不询问：不备份、不启用回滚

# 2. 重启 DeepSeek Harness
# 3. 设置 → Agent 预设 → CUSTOM 分组 → 选「网课模式」
# 4. 若新任务选择器里看不到它：通用设置 → 打开「代码工作工具」
```

**备份与回滚默认关闭。** 一次普通安装会在动任何东西之前问你两个问题：

```text
[?] 是否在修改前备份配置档 package.json？ [y/N]
[?] 是否保留它作为还原点（之后可用 -Rollback 还原）？ [y/N]
```

两者的组合结果：

| 备份 | 还原点 | 行为 |
|---|---|---|
| 否 | 否（默认） | **不产生任何备份文件**，装完没有可回滚点 |
| 是 | 否 | 生成临时备份作本次兜底，**安装成功后自动删除** |
| 是 | 是 | 保留还原点，装完打印 `.\install.ps1 -Rollback "<路径>"` |
| 否 | 是 | 会追问「回滚依赖备份，是否同时打开备份」；拒绝则回滚关闭且**仍不建备份** |

`-DryRun` / `-VerifyOnly` / `-Rollback` / `-NonInteractive` 四种模式不询问。
装完脚本会**逐文件比对 SHA-256**（不是只数文件个数），内容对不上直接失败并给出回滚命令。

### 浏览器

一般不用手动开 —— 插件按 `DSH_BROWSER_PATH` → 平台常见路径 → `PATH` 的顺序自己找浏览器，
自己带 `--remote-debugging-port` 拉起来（Chrome / Edge / Chromium 任一）。

想自己控制浏览器时手动开一个也行：

```powershell
chrome.exe --remote-debugging-port=9222 --user-data-dir="$env:USERPROFILE\.dsh\xuexi\browser-profile"
```

⚠️ 必须带 `--user-data-dir`：不带的话 Edge 会把命令交给你正在用的那个实例 ——
窗口被抢走，而且永远不会绑上 9222。登录态就存在这个 profile 里，跨会话复用。

## 快速开始

装好 → 重启 DSH → 切到「网课模式」→ **在插件自己的那个浏览器窗口里翻好要做的那一页**，然后说：

```text
接管浏览器，把这一页的任务做完
```

> ⚠️ **在哪个浏览器里开页面？** 插件会自己拉起一个带 `--remote-debugging-port` 的浏览器实例
> （独立 profile，登录态存在 `~/.dsh/xuexi/browser-profile`，跨会话复用）。
> **你要开的页面就在这个实例里开** —— 它会出现在 `eye_open` 列出的 `tabs` 里。
>
> 但有个坑：你在 DSH 里打字时，那个浏览器窗口是失焦的，而插件靠"哪个标签页可见"来认
> "用户正在看的那一页"—— 失焦时**所有**标签页都报不可见，它就可能绑回自己那一页。
> 所以 `eye_open` 会把「**不是插件动过的**」标签页单独列出来；看到你开的那一页，
> 让模型用 `hand_tab({ i })` 切过去就行（**别让它用 `hand_goto`**，那会把你翻好的页面顶掉）。
> 2026-10-17 真机就这么对错过：用户开了马原章节页，插件眼里始终只有它自己那个。

一次典型会话（工具调用由模型自己决定，你只看结果）：

| 步骤 | 它在做什么 |
|---|---|
| `eye_open` | 接管浏览器，**绑定到你正在看的那一页**（不会替你跳页） |
| `eye_see` | 报这一页有几处要处理、每处是「挑」还是「写」、完成标记是什么 |
| `hand_play` / `hand_read` | 播视频 / 慢翻文档（原速，不拖进度条） |
| `eye_shot` | 看不清就截图，图**直接进上下文**，你看得到 |
| `hand_pick` / `hand_write` | 在页面上作答 |
| `eye_check` → `hand_submit` | 页面 == α == β 三方比对通过才交 |

做完它一次性汇报：做了什么 / 要你处理什么 / 主动跳过了什么。
它**不会替你填账号密码，也不会破解验证码** —— 这两条是写在提示词里的行为约定
（靠它自觉，不是代码拦截），真遇到了就记进待办交给你。

## 17 个工具

分三组：**眼（6）** 只报事实、**手（6）** 只做一个动作、**兜底（5）** 只能由代码守住。

### 眼（6）—— 只报事实

| 工具 | 干什么 |
|---|---|
| `eye_open` | 接管浏览器并**绑定到用户正在看的那个标签页**；返回开着哪几个标签页、接的是哪个、登录没有、以前的笔记。**不会导航用户那一页**，幂等 |
| `eye_see` | 这一页有哪几处要处理，每处标明是**挑**（pick）/ **写**（write）/ **按钮** / **媒体**，有几个选项、现在选了什么、有没有「已完成」标记 |
| `eye_paper` | ★ **整卷一次拿**：按屏幕顺序编成 1..N，附题目区的图（超长自动分段）。做题的子 Agent 不会滚动，必须一次给它完整的图 |
| `eye_list` | 通用眼睛：这一页**所有能点能填的东西**，每个一个编号（**含内嵌窗口**）。不判断哪个该点 |
| `eye_shot` | 截图，**图直接放在返回里** —— 模型确实能看到，不是只给路径 |
| `eye_check` | 交之前复核（**只读**，跑多少次都不影响页面）。八条全过才发**票据**。参数 `ignore` / `ignoreWrite` 用来排除「不是题」的挑选项与输入框 |

`eye_shot` 的省图三问（截图很贵）：

- 这问题 `eye_see` 的数据（`areas` / `marks` / `done`）能答吗？能就别拍。
- 必须拍的话，整页还是某一处？**优先按编号裁那一处** —— `eye_shot({ "i": "<区编号>" })`，
  自动算矩形，pick 区会取**整组选项的并集**，比整页小一个数量级。
- 这张图是给复核员看的吗？是就 `embed: false` 只落盘，把 `file` 路径发给它（它用 `read_image` 读）。

页面内容跟上次看时相同、且之后没动过手 → 默认**不重烧**（返回「未变」）；确实要就 `force: true`。
（去重只对**裸调用**生效：给了 `full` / `clip` / `i` 的调用一律照截 —— 你要它有理由。）

### 手（6）—— 只做一个动作

| 工具 | 干什么 |
|---|---|
| `hand_click` | 点（编号 / 可见文字 / 屏幕坐标，三选一）。返回里会告诉你**页面怎么变了** |
| `hand_pick` | 在可挑区里挑选项。单选 / 多选 / 判断 / 下拉**对它都是同一件事**；只认页面上真实存在的选项，给了没有的会 `rejected` 并列出实际有哪些。**点完会回读**：页面没真的选中就报 `PICK_NOT_APPLIED`，不谎报成功 |
| `hand_write` | 在可写区写字，写完**回读**实际内容（不是「我应该写上了」） |
| `hand_scroll` | 滚。每步之间**已自动停顿**，所以没有（也别传）`dwellMs` 这类参数；想慢翻就小步多滚 `{ "px": 300, "times": 20 }` |
| `hand_goto` | **唯一的导航**：跳网址 / 后退 / 刷新。工具绝不自作主张跳页 |
| `hand_tab` | 换浏览器标签页（浏览器顶上那一排，不是网页里的页签） |

### 兜底（5）—— 只有这两类动作需要代码兜住

| 工具 | 为什么必须由代码守 |
|---|---|
| `hand_play` | **铁律**：原速 1x、永不拖进度条、永不伪造心跳、严格串行。参数里**故意没有** `seek` / `heartbeat` / `jumpTo` / `percent`；`rate` 只在**用户明确要求倍速**时才传。多视频页面用 `target` 指定播哪个 |
| `hand_read` | **慢翻一个文档到底**：回顶 → 小步 300px → 每步停 1 秒 → 到底。文档类任务点对翻阅节奏敏感，大步快跳**不计「读过」** |
| `hand_submit` | **做错回不了头**：不接受任何答案（只读页面）、没有有效票据就交不出去，交之前自己再走一遍八条。交完**验证是否真交上**：`ok:false` 时 `SUBMIT_NEED_CONFIRM` 表示还差一次确认框点击、`SUBMIT_UNCONFIRMED` 表示没有交上的迹象 —— **两种情况都不要再提交一次** |
| `hand_note` | 笔记本 + 给用户的待办清单（`lesson` / `pending` / `skip` / `general`），下次 `eye_open` 带回来。新笔记带 `replaces` 可作废被推翻的旧经验 |
| `hand_verdict` | **复核员专用**：登记复核结论。主脑调它会返回 `LEAD_CANNOT_JUDGE`（那是对的）。`picks` 接挑的（键 `n`）、`writes` 接填空/简答（键 `w`）、`uncertainWrites` 接不会写的；看不清回 `__need_shot` 要特写 |

> 复核员（子智能体）只开放 `hand_verdict` 与 `read_image`；
> 它调其它手眼工具一律返回 `NOT_THE_LEAD`。

## 典型流程：做完一页

```text
① 先数清楚：eye_see 看这一页有几处、每处是什么、完成标记在哪
② 一处一处做：媒体 hand_play / 文档 hand_read / 题 hand_pick + hand_write
③ 做完一处回头确认：标记变了没有（没变先刷新一次再看 —— 标记是页面加载时渲染的）
④ 有题要交：看图 → 自己定 → 派两个复核员 → eye_check → hand_submit
⑤ 做不来的记 hand_note({ tag:"pending" })，继续下一处，收尾一次性汇报
```

两条省时间、也省得白干的经验：

- **一页常常挂着好几处**，不要做完一个就翻页。
- **「播完了」和「记上了」是两件事**：`finished` 只说明播放器到了末尾，
  任务点记没记上是服务端的事，工具读不到就**不许替它下结论**。
  看到「未完成」的定式动作是**先刷新一次**；刷新后仍「未完成」才是真没记上 ——
  **别原地重播**，重播治不了「没记上」，只会白等一轮。

## 做题：α 作答，β 盲答校验

答题是全站唯一**做错回不了头**的动作（一般不给重做），所以交之前要两份**独立**结论：

```text
① eye_paper({}) → 整卷一次拿到：题号 1..N + 题目区的图（超长自动分段）
   ★ 题干只在图里 —— DOM 文字可能被字体搅过

② spawn_teammate 起 α → 派活：items + 图的文件路径
   不给：任何答案
   α 用 hand_verdict 登记结论（picks 挑的 / writes 写的 / uncertain 拿不准的）
   ★ 登记的键用 items[].key，**不是题号 n** —— 页面上有非题的可挑区时两者会差几位

③ 再起 β → **派同一份活，先不给 α 的答案**
   ★ β 必须盲答。给了就是抄，校验等于没有。
   β 同样 hand_verdict 登记自己的独立结论

④ 把 α 的答案发给 β：逐题对比，不一致的说清哪个对、为什么
   ★ β 只报告，不改自己的登记

⑤ 照 α 的答案落盘（主脑只搬运，不判断）：
   hand_pick / hand_write 按 items[k].i 写进页面

⑥ eye_check 三方比对（**页面 == α == β**）→ 八条全过才发票据
   不一致 → 只把「分歧的题号」告诉 α 重答，最多 2 轮；
            2 轮仍不一致 → hand_note({tag:"pending"}) 交给用户

⑦ hand_submit
⑧ 交完看返回：ok:true 才算交上；SUBMIT_NEED_CONFIRM 用 hand_click 点确认框；
   SUBMIT_UNCONFIRMED 先 eye_see 确认 —— **两种情况都不许再 hand_submit 一次**
```

**为什么主脑的答案必须落在页面上**：旧版主脑把复核员的 JSON 原样转发，
6 次提交和复核员给的 6 份一字不差 —— 实质只有一份判断，一个错就没人兜住。
现在工具直接读页面上的 `filled`，**想报一个假答案，它做不到**。
主脑落盘时点错一个选项，`filled` 立刻对不上，闸门当场拦。

**没有后门**：不一致时**永远不发票据**，没有票据就交不出去。
放行只有一条路 —— 复核员拿到特写后重新登记、且新结论一致。
登记是「每人一份当前结论、整体覆盖」，身份由 `ctx.agents` 判定，**不靠自报**。

`eye_check` 会拦这八条：

| # | 拦什么 | 错误码 |
|---|---|---|
| 1 | 挑的地方还空着 | `EMPTY_PICK` |
| 2 | 选了页面上没有的项 / 数量越界 | `OUT_OF_RANGE` |
| 3 | 写的地方是空的 | `EMPTY_WRITE` |
| 4 | 写字处的答案和复核员登记不一致 | `WRITE_DISSENT` |
| 5 | 复核员不够两份 | `NEED_TWO_REVIEWERS` |
| 6 | 三份不一致 | `REVIEWERS_DISSENT` |
| 7 | 还有拿不准的 | `HAS_UNCERTAIN` |
| 8 | 你指定的那个「交」按钮找不到 | `NO_SUBMIT_TARGET` |

写字的题查两条：① 空着没有（`EMPTY_WRITE`）；② 你写的和复核员登记的是否一致
（`WRITE_DISSENT`）—— 肉眼看着一样、只是标点空格不同的由 `normText` 归一化吸收。
页面上不是题的输入框（右上角「搜索」框就是典型）也会被算成一处待答填空题，
空着就一直拦住提交，用 `eye_check({ ignoreWrite:[w] })` 排除它。
主脑自己也要看一眼写得对不对，拿不准就 `hand_note({ tag:"pending" })` 交给用户。

票据有时效（**15 分钟**），且页面一动（点 / 写 / 翻页，滚动和截图不算）就作废。

### 已知限制

- **题目身份 = `targetId + url + 结构`**（每处的序号与选项数）。同一个标签页、同一个 URL 下，
  如果两套题的"每处选项数"完全一样，会被判成同一套题（同页两个结构相同的测验区块、
  或 SPA 换了内容但不换 URL 都属于这种）。失败方向是安全的：复核员登记的答案对不上新页面，
  走查会判 `REVIEWERS_DISSENT` 不发票据，不会静默交错。
- **元素编号每次扫描都变**，所以"看完攒一批编号到后面用"必然失败 —— 看完就动手。
- **选项被页面框架重渲染后，编号标记会丢**（判断题最常见）。
  现在有结构路径兜底：`hand_pick` 按 `nth-of-type` 链把元素找回来、补挂标记再点
  （返回里 `how:"click-by-path"`）。如果连元素本身都被换掉，仍会如实报
  `PICK_NOT_APPLIED`（不假装成功），换 `eye_list` + `hand_click` 绕过去。

## 边界与铁律

**铁律六条**，但拦的层级不一样：

| 铁律 | 谁来拦 |
|---|---|
| 原速 1x ｜ 永不拖进度条 ｜ 永不伪造心跳 ｜ 严格串行 | **参数层堵死**：工具根本不接收这些参数（测试 `C7` 断言禁 `seek` / `heartbeat` / `jumpTo` / `percent`） |
| 不破解验证 ｜ 不代填账号密码 | **行为约定**：写在提示词里靠模型自觉，代码不拦（`hand_write` 有能力往任何输入框写字，但它不被允许这么做） |

```text
原速 1x ｜ 永不拖进度条 ｜ 永不伪造心跳 ｜ 严格串行 ｜ 不破解验证 ｜ 不代填账号密码
```

- **倍速**：默认 1x 是我们自己的底线；但「别人改成几倍」是事实，工具会如实报告、不纠回去。
  只有**用户明确要求**时才传 `rate`。
- **人脸 / 抓拍直接拒绝** —— 它要求摄像头前坐着真人，原理上做不到。

**四类错误**（返回里的 `category`，决定该改自己还是该改看法）：

| category | 意思 | 页面动过吗 |
|---|---|---|
| `ARG` | 调用格式写错了 | **没动** |
| `USAGE` | 格式对，组合不对 | **没动** |
| `WORLD` | 屏幕上真没这东西 | 可能动过 |
| `TOOL` | 浏览器掉了 / 上一个任务还在跑 | —— |

## 配置与环境变量

| 变量 | 干什么 |
|---|---|
| `DSH_BROWSER_PATH` | 显式指定浏览器可执行文件。设了但文件不存在会**直接报错**，不悄悄换一个 |
| `DSH_CDP_TIMEOUT_MS` | 单条 CDP 命令的超时（默认 **60000**）。浏览器假死时最坏也就是超时后一句明白话，不挂起 |

**过程文件落在哪**：`<工作区>/.xuexi/`（截图、笔记、记账）—— 跟对话在一起，好清理。
**机器状态**：`~/.dsh/xuexi/`（`browser-profile` 登录态跨会话共用；`load-diag.log` 是装载诊断日志）。

npm test          # 静态断言集：356 条，不需要浏览器
npm run test:live # 真浏览器集成验证：23 个用例 / 50 条子断言，没有浏览器就跳过

`npm test` 分七组：

| 组 | 覆盖什么 |
|---|---|
| A | 参数校验（含**零副作用**的结构保证） |
| B | 复核闸门（八条 + 票据 + 登记覆盖） |
| C | 工具表面（16 个、前缀、并发标志、铁律参数里不许有 `seek` / `heartbeat` 这类作弊口子） |
| D | 痕迹检查（代码与提示词里不许有平台字样、不许写死网址） |

### `npm run test:live`：真浏览器集成验证

**这套不开浏览器跑不了**，而且它测的东西和 `npm test` **基本不重叠**：
它自己拉一个 chromium（临时 profile + 两个只监听 127.0.0.1 的静态服务器），
拿 `test/fixture/` 里三个静态页驱动**产品自己的代码路径** ——
`index.js` 的 17 个工具经 mock ctx 真注册、真执行，几何与登录态走 `lib` 的真实现。

| 组 | 验什么 | 为什么静态断言替不了 |
|---|---|---|
| L1 | `eye_open` 绑定 fixture 页（不导航、幂等） | — |
| L2 | `eye_see` 的编号 / 顺序 / 选项 / `filled` / 签名，且**报出的编号与 DOM 上挂的 `data-dsh-h` 必须是同一个**；`eye_paper` 的整卷编号 1..N、每题落盘编号、题目区矩形与分段 | 这类错内部完全自洽（工具自己读自己写都对），只有对拍能发现 |
| L3–L5 | 按编号 `hand_click` / `hand_pick` / `hand_write` → DOM 的选中态与 value 真的变了 | 静态断言只看得到返回值，看不到页面 |
| L6 | `eye_shot` 省图三问的全路径：没变不重烧 / `force` 照办 / **按编号裁剪的 PNG 尺寸对拍** / `embed:false` 只落盘 / 坏编号明确报错 | 裁剪几何只有量了才知道 |
| L7 | 跨域 iframe 的页面坐标矩形 + 命中 / 落空 | 坐标系换算 |
| L8 | `loginState`：主窗口没有 → false；**跨域 iframe 里的密码框也必须算** | 只扫主窗口会漏判 |
| L9 | socket 健康层：关掉浏览器 → `isAlive=false`、`onDead` 广播、`send` 立即 `SOCKET_DEAD` | 真 socket 才会死 |
| L10 | `findBrowserExe` / `launchBrowser` 的发现顺序、跨平台、环境变量指错时报错 | — |

⚠️ **两种情况下它会静默跳过并 exit 0**（都不是代码问题，但意味着这次什么都没测）：
① 本机没找到 Chrome / Edge / Chromium；② chromium 起来了但调试端口 20 秒没就绪。
看到这两行输出就是没过一遍 —— **别把它的"全绿"当成验证过**。

## 常见问题

**我明明打开了网页，模型却说"没有你在用的页面"？**
它大概率是绑回了自己那一页。`eye_open` 会把「**不是插件动过的**」标签页单独列出来
（带 `[i]` 序号和是否可见）——找到你开的那一页，让模型用 `hand_tab({ i })` 切过去即可，
**别让它用 `hand_goto`**（那会把你翻好的页面顶掉）。
首次使用需要你在插件拉起的那个窗口里登录一次，登录态存在
`~/.dsh/xuexi/browser-profile` 里跨会话复用。

**预设列表里看不到「网课模式」？**
它在 **CUSTOM** 分组下（带 `name` 的预设都归自定义）。另外确认
通用设置 →「代码工作工具」已打开，否则新任务选择器不显示自定义预设。

**装完显示「加载失败」？**
看 `~/.dsh/xuexi/load-diag.log`：有 `module-eval start` 没有 `module-eval ok`
= import 阶段报错；有 `apply start` 没有 `apply done` = 注册时报错，堆栈就在下面几行。

**连不上浏览器 / 报 ECONNREFUSED？**
插件会自己拉浏览器。拉不起来通常是本机没装 Chrome / Edge / Chromium，
或 `DSH_BROWSER_PATH` 指向了不存在的文件（指错会**明确报错**，不会悄悄换一个）。

**截图老返回「未变」，是不是坏了？**
不是。页面内容跟上次看时相同、且之后没有点/写/滚/翻页，就**不重复烧图**。
确实要一张新的就加 `force: true`。

**它会替我作弊刷课吗？**不会。前四条（原速 1x / 不拖进度条 / 不伪造心跳 / 严格串行）在**参数层就堵死**；
后两条（不破解验证 / 不代填账号密码）是**行为约定**，写在提示词里靠它自觉；
人脸抓拍直接拒绝。

**支持 macOS / Linux 吗？**
暂不提供支持。安装脚本只面向 Windows（PowerShell，带平台闸门）；
浏览器发现层已经按 `process.platform` 分派，但整套流程只在 Windows 上验证过。

**`-ProfileName` 能用吗？**
暂不建议使用：`scripts/patch-profile.mjs` 目前把配置档目录固定为 `desktop`，
用非默认配置档时打补丁与回滚会写到 `desktop`。等这个参数打通后再用。
